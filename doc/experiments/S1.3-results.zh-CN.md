# S1.3 本地协作与通用界面验收

2026-09-12。**本轮约定的 S1.3 本地协作与第一轮通用界面已实现并在当前 Mac 验证。** 这不代表 S1.2 的所有性能问题已经关闭，也不包含 S2 的签名、网络或分叉三方合并。

## 可直接使用的产物

- 新独立应用：`dist/viewer-s13/macos/Realm of Us.app`，默认携带 CC0 校准街区。保留旧 `dist/viewer/` 和各版房屋应用。

## 本地贡献闭环

实际使用打包的 Blender 插件，不把 JSON 占位对象当作真实模型：

| 版本 | 操作 | 完整快照 |
| --- | --- | --- |
| C0 / Founder | 建立 CC0 花园与地标 | 2 个实体 |
| C1 / Alice | 从 C0 元数据 clone，在北侧选区新建亭子 | 保留原 2 个实体，新增 `north_house` |
| C2 / Bob | 从 C1 元数据 clone，在南侧选区新建树 | 保留原 3 个实体，新增 `south_tree` |
| C3 / 编辑副本 | 只 checkout 北亭源 Collection，在 Blender 中整体平移 1 m，重导出 | `north_house` 保持 ID；其余实体保留 |

C1→C2 的 diff 只有新增 `south_tree` 和 `0,0,1` page；C2→C3 只有修改 `north_house` 和 `0,0,-2` page。C0/C1/C2 都能固定版本打开；同一北侧视点下 C0 没有亭子，C1 有亭子。截图在上述 run 的 `viewer/c0.png` / `c1.png`。

完整 C2 副本的提交与 page 元数据合计 **67918 bytes**，clone 结束时 **0 个 GLB、0 个 .blend**。显式补资产后 C2 只存 4 个 GLB，即两个原始对象加两次新贡献，未复制未变化版本的字节。单实体编辑 checkout 只复制 **1 个 .blend、0 个 GLB**，实际 Blender 回读、修改和再导出通过。

只 clone `3,0,3` 的目录副本有 240 个已知空块、16 个未知块：所有空块共享同一个空 page，取得它便可验证这 240 个块为空；有内容的 page 没取得，继续显示 Unknown metadata。它没有把“缺页”判作“空世界”。

## 当前 Mac 运行结果

Apple M3 / 24 GiB，macOS 26.3，Blender 5.2.1 LTS，Godot 4.7.2，Go 1.27.1。独立应用使用 Metal / Forward+、1920×1080、Quality，每轮 36 s，内部基准取消 60 FPS 上限；正常交互仍上限 60 FPS。各轮独立启动，未清理系统文件/驱动缓存，未隔离普通桌面应用。

**首次准备等待仍是问题。** 本轮新应用第一次校准测试的引擎初始资产准备为 32.30 s，进程到入口首帧为 40.78 s；重复启动降至 1.07 s。尚未隔离引擎初始化、驱动、着色器和系统负载等因素，不能归因于仓库协议，也不能据重复启动数字宣称首次进入已达标。

V3 房屋本轮检查通用浏览与可选演示往返，未重新进行完整 16 视点性能矩阵。S1.2 记录的约 75.10 MiB 入口闭包仍超 5 MiB 目标，首次准备等待及 `7 RIDs ... Texture ... leaked` 警告保留为问题；本轮第一组房屋窗口运行也出现过该警告。此后某次没有警告不构成已修复证明。

## Git 复用实验与决定

使用本机 Git 2.50.1，在 `build/s13/git-probe/run-20260912T211359035419Z/` 建立独立实验仓库：

- 每实体一个 JSON，Alice/Bob 修改不同实体时自动合并；同一实体同一字段修改产生明确文本冲突。
- 1,600,000-byte 外置模型文件没有进入 Git；tracked 文件只有 ignore 与两个实体 JSON。
- 经本地 `file://` bare remote 开启过滤，`--filter=blob:none --no-checkout` 留下 6 个缺失 blob；只 checkout 北侧实体后仍缺 5 个，工作区只出现北侧 JSON。

**阶段决定：保留 Go 本地引擎，不同时维护一套 Git commit 映射。** 实验表明 Git 可复用元数据历史、文本差异、部分 clone 和 merge；没有证明 Git 不适用或自建更快。但空间索引重建、选区依赖闭包、二进制审阅和空间冲突仍需框架逻辑，正式公开元数据/签名跨 fork 的编码也没有在本实验实现。S2 字节协议冻结前再审阅是否采用 Git；若采用，必须以一套 commit ID 为准，并明确迁移本地实验历史。

## 本轮边界与保留事项

S1.3 完成的是本地文件仓库、顺序贡献和通用查看器第一轮。没有账号、签名、公开 release/ref 权限、P2P、自动网络拉取、分叉三方合并、GC/磁盘配额、版本写入 UI，也没有多人实时位置同步。

元数据采用有界世界的完整 chunk→page 根，部分 page 可缺失；不是未来无限世界的层级树。checkout/diff/commit 要求完整元数据；源和运行时资产才按选择补齐。Go 校验字节哈希不等于模型内部结构有效，Blender/Godot 的既有资产预检查仍必要。

通用 UI 已从房源导览转为世界/版本/区域/实体，但仍是桌面实验界面：飞行相机无碰撞，实体选择用 AABB，写版本继续使用 CLI + Blender。样例控制仍通过少量兼容接口连接主查看器，可后续继续收敛；房屋灯光/材质和 UI 已独立到 samples。

失败的开发运行保留为诊断，包括最初测试脚本漏注册插件、旧生命周期测试仍修改 realm_path 而未切换独立 asset_root 的适配错误，均已修正并重跑。它们不计入通过记录。新的回执另存；原 S1.2 的 17 个保护文件、4 个输入产物和 100 个证据文件逐一校验未变，离线视频与 4K 静帧也未改。没有对项目 Git 执行暂存或提交；Git 原型的提交仅存在于忽略的实验目录。
