# S1.2 当前 Mac 实机验收

日期：2026-09-12。范围由用户限定为当前 Apple M3 / 24 GiB Mac；Windows/Linux、16 GiB 设备不纳入本轮。**本轮验收执行完成：三条路径的功能、前台帧率与内存通过；V3 入口体积未达到 5 MiB 目标，首次准备等待及通用界面调整列为后续项。** 机器可读证据见 [S1.2-mac-acceptance.json](data/S1.2-mac-acceptance.json)。

## 三条路径

| 路径 | 输入 | 检查 |
| --- | --- | --- |
| 基础浏览 | `build/s12/calibration/preview/realm.json`，50 个实体、4 个入口 | 坐标、尺度、跨块、自由移动、网格、局部加载/释放、前台性能 |
| 实时整屋 | `build/s12/villa-anahid/preview/realm.json`，V3 的 55 个实体、16 个入口 | 全部视点、厨房与家具、楼层/房间图、Quality / Performance、前台性能 |
| 创作与修改 | 安装 `build/s1/rou_authoring.zip`，带外部贴图的小模型 | 新建世界、标记、导出、源工程交接、可读文件名保存与重开、查看器重载变化 |

性能统一使用 `dist/viewer/macos/Realm of Us.app`。V1/V2 为历史对照；Cycles 精致客厅尚未转换为 S1 运行时实体，其视频与 4K 图片不作为实时性能证据，也不在本轮重渲染。

当前房屋展示 UI 的后续调整见 开放世界查看器要求。本轮验证展示功能，不将其视为最终产品界面。

## 测量条件

- Apple M3 / 24 GiB、macOS 26.3、接电；Blender 5.2.1 LTS、Godot 4.7.2、Metal Forward+。
- 输出 1920×1080。Quality：100% 3D 分辨率、4× MSAA、SDFGI/SSIL；Performance：75% 3D 分辨率、2× MSAA、关闭 SDFGI/SSIL。
- 校准街区用 Daylight，每轮 36 秒；房屋用默认 Dusk，每轮 132 秒。按现有每 8 秒切换入口的固定导览运行，切换包含淡入淡出，并非连续匀速飞行。
- 独立应用以 `/tmp` 为工作目录运行；每轮启动新进程，正常桌面应用保留，操作系统文件缓存和驱动缓存未清空。因此“首次”仅指本轮该场景/模式的首次运行，不是首次安装或严格冷缓存。
- 统计排除初始区域资源就绪及其后 2 秒，测量时解除应用 60 FPS 上限。只有所有统计帧均保持焦点的结果才有效。
- “进程到区域首帧”从创建进程到观察到初始资源队列清空后的渲染完成回执，轮询间隔约 0.2 秒；不表示最早的空窗口画面，也不声称已测量人的操作响应时间。
- RSS 为每 0.2 秒采样的进程驻留内存，不等于 GPU/驱动全部分配量。

复现性能测量：

```sh
python toolchain/build/benchmark_viewer.py \
  --executable "$PWD/dist/viewer/macos/Realm of Us.app/Contents/MacOS/Realm of Us" \
  --realm "$PWD/build/s12/calibration/preview/realm.json" \
  --report build/s12/mac-acceptance/calibration-quality-first.json --seconds 36 --daylight

python toolchain/build/benchmark_viewer.py \
  --executable "$PWD/dist/viewer/macos/Realm of Us.app/Contents/MacOS/Realm of Us" \
  --realm "$PWD/build/s12/villa-anahid/preview/realm.json" \
  --report build/s12/mac-acceptance/villa-quality-first.json --seconds 132
```

房屋性能档追加 `--balanced`，重复运行使用另一个报告文件名。各次测量串行进行；测量期间不运行 Blender、其他查看器或离线渲染任务。

## 前台性能结果

| 样例 / 运行 | P50 / P95 / P99 帧时间（ms） | 峰值 RSS（MiB） | 进程到区域首帧（s） |
| --- | ---: | ---: | ---: |
| 校准 Quality / 首次 | 10.90 / 12.87 / 14.35 | 476.89 | 1.26 |
| 校准 Quality / 重复 | 10.88 / 13.00 / 14.32 | 472.25 | 1.05 |
| V3 Quality / 首次 | 22.39 / 24.97 / 25.80 | 612.94 | 29.87 |
| V3 Quality / 重复 | 23.81 / 26.70 / 28.35 | 475.27 | 2.11 |
| V3 Performance / 首次 | 9.18 / 11.43 / 12.83 | 462.31 | 1.71 |
| V3 Performance / 重复 | 10.27 / 12.70 / 14.16 | 462.59 | 1.93 |

六轮有效样本的 `foreground_measurement_valid` 均为 `true`，失焦统计帧为 0，资产拒绝为 0。各轮 P95 ≤33 ms、峰值 RSS ≤2 GiB。校准街区每轮导入 76 次、卸载 48 次；这是跨入口重复加载次数，不是唯一实体数量。房屋每轮导入 55 次、卸载 0 次。

V3 Quality 本轮首次进程到区域画面约 29.87 秒，重复运行约 2.11 秒。启动准备仍是体验问题；本轮没有做驱动编译归因实验，不能仅凭重复运行更快就断言全部等待都来自着色器。Performance 测量发生在 Quality 之后，也不能用其约 1.7 秒冒充首次安装的准备时间。

## 内容预算

默认查询使用相机到 chunk AABB 的 48 m 距离，按实体引用汇总并按资产哈希去重。入口字节数包括当前完整目录与所需 GLB，不包括创作源 `.blend` 和查看器内置软件资源。

| 样例 | 首入口实体 | 首入口 GLB + 目录 | 5 MiB 目标 |
| --- | ---: | ---: | --- |
| 校准街区 | 28 / 50 | 384,110 bytes / 0.37 MiB | 达到 |
| V3 实时整屋 | 55 / 55 | 78,750,251 bytes / 75.10 MiB | 未达到 |

房屋在默认查询范围内覆盖所有实体，因此这条导览没有加载取消/卸载，不能用它单独证明流式资源释放。校准街区覆盖局部加载与卸载；快速跳转取消和篡改拒绝由已有生命周期测试补充。

房屋整体入口超出目标不等于单个 GLB 违反硬性上限。帧率与内存结果应与入口体积、首次准备等待分别评价；不能仅凭流畅就宣称所有内容预算达标。

## 窗口验证方式

桌面自动化连接本轮仍失败（`Sky Computer Use native pipe startup failed`），系统桌面截图也无法取得。使用实际 Blender/Godot 窗口、程序调用操作或注入输入事件，以及引擎自身保存的渲染画面；结果不表述为人工逐按钮测试。

`toolchain/tests/blender/verify_authoring_ui.py` 在使用隔离偏好目录的全新 Blender 进程中安装真实 ZIP，复用创建/编辑/重开检查并截取面板。`client/tests/rendered_workflow.gd` 在真实 Godot 窗口中驱动与独立应用相同的查看器源码；性能另用未修改的导出应用测量。文件选择由回调输入驱动，鼠标/键盘导航使用输入事件。

所有本轮工作文件、原始报告和截图保存在 `build/s12/mac-acceptance/`。受检查进程重叠影响的房屋重复样本及中断测量保留在 `excluded/`，不进入最终统计。

主要证据路径：`authoring/{create,edit,reopen}-report.json`、`{calibration,house,authoring}/viewer/report.json`、`native/{calibration,house,authored}.json`。对应 PNG 与日志同目录保存。窗口流程的本机编排脚本留在 `build/s12/mac-acceptance/run-windowed.py`；可复用测试源码为 `toolchain/tests/blender/verify_authoring_ui.py` 和 `client/tests/rendered_workflow.gd`。

## 后续项与关闭范围

- V3 入口 75.10 MiB 超过 5 MiB 目标；当前查询粒度没有让整屋按房间逐步加载。
- V3 Quality 本轮首次区域画面约 30 秒，启动准备需要单独优化和归因。
- Godot 房屋窗口流程退出时仍有 `7 RIDs of type "Texture" were leaked` 警告，与历史房屋实验一致。尚未定位归属；本轮短时 RSS 达标不等于已证明长期驻留或退出资源清理无问题。独立发行包日志未输出同类警告，不能据此认定已经修复。
- 当前材质/家具仍为简化实时样例；浴室部分高光偏亮，房间图小矩形存在标签截断。功能通过不表示达到 Cycles 样片的美术质量或最终 UI 质量。
- 通用开放世界界面按 后续要求 调整；其他硬件和平台以后另测。

完成的是用户限定的当前 Mac 验收执行，不能表述为所有内容预算、最终产品界面或跨平台 S1.2 全部达标。S1.3/S2 范围没有提前计入。原有 S1.1/S1.2 历史 JSON 回执、冻结空间文件和离线视频/图片保持不变；本轮未暂存或提交 Git。
