# S1.2 工具完善与验收记录

日期：2026-09-12。**当前 Mac 的本地功能、前台帧率与内存已验证；V3 入口体积超出目标，启动准备和通用界面仍需后续调整。** 最新范围与结果见 [Mac 实机验收](S1.2-mac-acceptance.zh-CN.md)。操作见 创作与浏览指南；先前实现阶段的机器可读结果 [S1.2-closeout.json](data/S1.2-closeout.json) 保持为历史记录。

## 本轮实现

- Blender 插件增加默认世界入口；把选中的顶层模型包成实体根，保持原世界变换。提供世界名称与内容许可字段，空世界也能导出；默认观看入口在首个实体附近。
- 源工程可按实体名称或 ID 搜索，再验证源文件和 Collection 后追加。可读工作文件名由名称和稳定 ID 组成，使用 Blender 原生 Save As 选择位置。追加保留实体源许可，已有场景的名称与许可不会被覆盖。
- 独立检查源文件路径、长度、SHA-256、入口 Collection、实体 ID 和世界参数。导出时嵌入使用到的静态图片，写出后恢复作者的原图片打包状态；不支持的外部依赖明确报错。源库上限为 128 MiB/实体。
- 导出先在临时目录完成资产与目录验证，成功后替换当前目录；失败保留上一份有效目录。既有哈希对象也会检查实际字节，避免复用损坏文件。
- Godot 增加通用欢迎页、Open realm、Ctrl/Cmd+O、Reload，以及错误恢复、空世界和附近无内容提示。切换前先校验新目录；失败时保留当前世界。房屋专用材质、灯光与楼层界面只在房屋展示目录中启用。
- 通用桌面包默认命名为 `Realm of Us`，支持任意合法本地目录；打包前验证 GLB，应用只携带观看依赖。
- 增加 `verify_s12.py` 完整复现入口。性能工具可指定任意目录和独立应用，记录首帧完成时间、进程 RSS 以及窗口焦点；失焦运行会标记为无效前台测量。

没有改动 S1.1 的 Schema、共同向量及空间语义。`rou-preview/0.1` 保持不变，创作插件/导出器版本为 `0.2`。本轮没有实现仓库 checkout/commit、多人合并或 P2P。

## 先前锁屏测量与后续复测

本机为 Apple M3、24 GiB 统一内存，Blender 5.2.1 LTS、Godot 4.7.2，1920×1080、Metal Forward+。记录的是校准街区、36 秒观看窗口，帧统计排除初次区域就绪后的 2 秒。

| 观察 | 首区域就绪 | 帧时间 P95 | 峰值 RSS | 焦点与解释 |
| --- | ---: | ---: | ---: | --- |
| 独立进程首次测量 | 25.31 s | 998.31 ms | 634.41 MiB | 首次尝试，未记录焦点计数；不作为性能结论 |
| 加入焦点记录并请求前台后 | 9.59 s | 996.01 ms | 465.11 MiB | 129 个统计帧全部失焦；不作为正常浏览性能结论 |

第二次测量还记录到：打开目录到首帧渲染完成约 9.61 s，进程启动到观察到首帧完成约 11.41 s。没有清空操作系统文件缓存或驱动缓存，不把两次运行声称为严格受控的冷/热缓存实验。

此前 `lsappinfo` 显示前台进程为 `loginwindow`；请求应用前台仍未获得焦点。失焦统计中出现约 1 秒帧间隔，未达到正常浏览的有效测量条件。此结果不能用于宣称达到 P95 ≤33 ms，也不能据此判定模型在正常前台运行的性能。

第二次尝试的外部应用激活还启动了一个额外查看器实例，已退出该实例并移除此激活方式。当前工具仅由被测进程请求前台，并依据焦点计数标记测量是否有效；上述旧观测保留为排查记录。

桌面解锁后的六轮固定导览已完成，全部 `foreground_measurement_valid=true`。校准街区 P95 12.87–13.00 ms，V3 Quality 24.97–26.70 ms，Performance 11.43–12.70 ms，峰值 RSS 均低于 613 MiB。V3 首入口约 75.10 MiB，未达到 5 MiB 目标。用户将 16 GiB 设备及 Windows/Linux 移出本轮范围，完整条件见 [Mac 记录](S1.2-mac-acceptance.zh-CN.md)。

```sh
python toolchain/build/benchmark_viewer.py \
  --executable "$PWD/dist/viewer/macos/Realm of Us.app/Contents/MacOS/Realm of Us" \
  --realm "$PWD/build/s12/calibration/preview/realm.json" \
  --report build/s12/measurements/unlocked.json --seconds 36 --daylight
```

无账户、无外网的本地链路与资源行为已经验证；S1-A05 的当前 Mac 前台性能已补齐有效证据，内容入口预算未全部达到。源文件回读不是元数据 clone 或历史快照贡献，S1.3 范围不提前算作完成。
