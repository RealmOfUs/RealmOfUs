我希望把我们的共享建模框架做成“多人分布式协作开放3D元宇宙里的 git”。

* Step1: 验证并规范化：世界（realm）基本参数（大小、形状、分块、颗粒度等）、blender+godot 工具链、 view client。每一个realm类似于一个 git repo，由发起人创建并规范其基本参数。参与者可以 clone 该realm并贡献其中分块里的3D模型。模型通过blender创建，由 godot 搭建 view client 使用户可以自由 view 世界里的存在 3D 模型的分块。

* Step2: 分布式 p2p 协议及架构设计。由于模型资产比较重，不像git代码可以低成本全局 clone，clone realm时可以优先下载分块目录，分块模型资产本身则先进行签名加密保存在每个向外广播的节点，由 p2p 的方式按需拉取到本地。分块模型的版本、更新以realm中的记录为准。类似于每个 git 项目都有官方仓库和克隆仓库，除了发起人维护并公开的官方realm外，每个用户也可fork并公开自己的realm，也许后面会有类似“realmhub”的网站来集中管理并发布realm。

到此为止我们大部分有价值的工作已经做完了，核心是提供多人分布式开放3D世界的协作机制。也许我们可以将 view client 上架 steam 等平台盈利，甚至创建一个 “realmhub”平台，但这些都不属于核心架构。
